## 1. Проект — теперь два продукта на одном фундаменте

**Продукт 1 — «школа диаспоры» (проект основательницы, SPEC v2.0).** Онлайн-школа для еврейских детей из русско- и англоязычных семей диаспоры. Формула: «как Alpha School, только плюс еврейское» — светская академика ~2 часа в день на адаптивных платформах, еврейский блок (традиция/история/тексты) — уникальная ценность. Ниша проверена глубоким ресерчем и пуста.

**Продукт 2 — «онлайн-хедер» (вводная от Льва, 07.08.2026).** Партнёрство с **Равом Ади Ханукаевым** (Хабад, хедер в Атланте, chederat.com; сайт из облачного окружения недоступен — сетевой фильтр) — наставником (машпиа) Льва. Сейчас у хедера: мальчики, 1–5 классы, ~30 детей; Рав хочет строить школу и расширять аутрич, но ограничен в бюджете. Идея: онлайн-хедер снимает географический потолок — полная школа (EN + иврит) для религиозных семей, которым физический хедер не по карману, и для городов без школы; девочки — второй очередью; цель — тысячи учеников. **Амбиция (Лев): топ-тир, школа-претендент на лучшую за всю историю еврейского образования** — иммерсивные живые материалы + персональная адаптивная программа каждому ребёнку; доступность по цене — следствие модели, а не её смысл. Ключевое требование Льва: сохранить социальную ткань (хеврута, машпиа, живые встречи, городские хабы) — «онлайн ≠ одинокий ребёнок с айпадом»; расписание с утра до вечера, интерактив и иммерсивность (карты сугий, генерация иллюстраций по пройденному, схемы сфирот, аккуратная геймификация тфилы, каталог разрешённых игр на переменах). Всё разобрано в `КОНЦЕПЦИЯ_онлайн-хедер_v0.1.md` — читать обязательно.

Технический фундамент общий: LMS в аренду, отдельный ИИ-тьютор, «клей»-база прогресса, конвейер контента с человеческим ревью.

## 3. Утверждённые решения по продукту 1 (НЕ переспрашивать, НЕ пересматривать без запроса)

1. **Продукт**: полная школа, 2 режима: «Дополнение» ($59/мес, пилот $39; легален везде, включая Германию, где хоумскулинг запрещён) и «Полная школа» (~$199–249/мес; США/Канада/UK/Израиль). Юридический статус — программа для хоумскулинга, как AFA.
2. **Возраст старта**: 8–11 лет (потом 6–13). **Языки**: русский и английский сразу (RU-мастер, EN с лагом ~2 недели).
3. **Треки**: культурный / традиционный (по умолчанию) / религиозный — один материал, три редакции подачи (~10–20% различий).
4. **Контент MVP**: курс А «Еврейский год» (school-paced, 34 юнита, семейные задания) + курс Б «История нашего народа» (student-paced, mastery ≥80%, 24 юнита) + модуль В «Иврит традиции» (15 мини-уроков; полный курс иврита — ВНЕ MVP).
5. **Светское ядро НЕ производим** — собираем из готовых адаптивных платформ (EN: Khan/IXL-класс; RU: Учи.ру-класс — выбор = задача недель 1–2). Параллельно запросить условия лицензии Timeback (платформа Alpha).
6. **ИИ-тьютор в MVP** (вариант C): приватный инстанс Claude, сократический метод, 3 профиля рамок по трекам, бета с логированием и еженедельным ревью диалогов. Без камер и слежки. Архитектурно — ОТДЕЛЬНОЕ мини-приложение рядом с LMS.
7. **Платформа**: арендуем готовый LMS (Teachable/Thinkific/LearnWorlds/GetCourse — выбрать); своя платформа растёт постепенно; перенос к себе — после 100+ семей. Требование: экспортируемость данных.
8. **Запуск двумя волнами**: волна 1 — сентябрь 2026, к Рош а-Шана 12.09 («Дополнение» + бета тьютора); волна 2 — январь 2027 («Полная школа», обкатка светского стека осенью на 3–5 семьях-добровольцах).
9. **Критерий успеха MVP**: 20–30 платящих семей за семестр (≥8 в «Полной школе»), ≥70% доходят до конца, ≥50% продлеваются.
10. **Производство контента**: основательница + Claude пишут → педагог-ревьюер проверяет каждый юнит (для религиозного трека — рав) → ни один ИИ-текст не публикуется без человеческого ревью. *(Для продукта 2 ревьюер-рав получает имя — Рав из Атланты, если подтвердит участие.)*
